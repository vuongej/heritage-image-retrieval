# Web demo

Giao diện: ô nhập truy vấn → grid ảnh → **facet chip bấm lại truy vấn được**.

```bash
npm install
npm run dev   # http://localhost:3000
```

Biến môi trường:

| Biến | Mặc định |
|---|---|
| `NEXT_PUBLIC_API_BASE` | `http://localhost:8000` |
| `NEXT_PUBLIC_TEST_API_KEY` | `gsk_test_dev_only` |
